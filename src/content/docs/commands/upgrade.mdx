title: tapid upgrade
description: Verify and apply a compatible signed release when release artifacts are available.
---

## Syntax

```text
tapid upgrade [OPTIONS]
```

The command is implemented to inspect and apply a compatible signed release. It fails closed when release metadata, signatures, trusted key material, or required artifacts are missing or invalid.

No asset-backed stable tapid release is currently available, so the normal public upgrade path cannot complete today.

## Options

```text
--endpoint HTTPS_URL
--keyring PATH
--destination PATH
--dry-run
```

`--dry-run` inspects and verifies a candidate without replacing the executable. The embedded production keyring supplies trusted keys by default; `--keyring` selects an explicit compatible keyring instead. The upgrade path does not use `main` as an implicit release source.

## Status

The command is part of the current CLI surface, but successful use depends on a compatible signed release manifest, trusted keyring, and available release artifacts. Source builds and development branches are not stable release evidence.
