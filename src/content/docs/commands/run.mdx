---
title: tapid run
description: Run an explicit root package script with forwarded arguments.
---

## Syntax

```text
tapid run <SCRIPT> [-- <ARGS>...]
```

Run a root script from `package.json` in the selected project directory. Tapid prepends the managed `node_modules/.bin` directory to `PATH`, forwards arguments after `--`, and returns the child process exit status.

## Options

```text
--project-dir PATH
```

Use a project directory other than the current directory.

## Examples

```bash
tapid run --project-dir ./example test -- --runInBand
tapid run dev
```

Root scripts can execute arbitrary project code through the platform shell. This is compatibility-oriented process execution, not a sandbox or security boundary.
